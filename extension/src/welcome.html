Perfect

Cursor’s hands in Chrome

Unofficial open-source MCP bridge. Not affiliated with Cursor, Anysphere, Google, or Anthropic.

How to connect (about 2 minutes)

  1. Click the Perfect icon (or open the side panel) — a bridge token is created on your machine.
  2. Press Copy setup prompt for Cursor.
  3. Paste that prompt into a Cursor chat and let Cursor merge only the perfect MCP entry.
  4. In Cursor Settings → Tools & MCP, enable perfect (toggle off/on if it was already on).
  5. When the side panel says Linked to Cursor, you are ready.

Permission modes

Default is Manual — Perfect asks before acting. Auto pauses on protected or new sites. Skip is dangerous; prohibited actions (for example Buy now / checkout) stay blocked.

Safety

  • Stop in the side panel or on-page HUD cancels work and detaches the debugger.
  • Agent tabs live in a visible green Perfect tab group.
  • The debugger permission is used only for local Chrome DevTools Protocol automation — no Perfect cloud.
  • You need Node.js 20+ locally so Cursor can run the MCP server via npx.

Try a prompt

After Linked, paste in Cursor:

Using Perfect: open https://example.com, take a snapshot, and tell me the main heading.

Or: search YouTube for a song and play it — Perfect chains navigate / wait / press, not a special search API.
