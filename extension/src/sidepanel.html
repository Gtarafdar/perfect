First-time setup

  1. Create your bridge token in Terminal: 
    npx -y @perfect/mcp setup

    Building from GitHub instead: node packages/mcp-server/dist/cli.js setup

  2. Copy the token the command prints (also in ~/.perfect/token.txt), paste below, click Link.
  3. Add Perfect to Cursor MCP (Settings → MCP), or click Copy Cursor MCP config and merge into ~/.cursor/mcp.json, then enable the server.

The token is a local secret so only your Cursor can drive Chrome — not a Cursor account password.

No token yet? Run setup in step 1 first.
