Connect Cursor

  1. Copy connect for Cursor (includes your bridge token in MCP env — generated here automatically).
  2. Paste into ~/.cursor/mcp.json (merge under mcpServers), or paste the chat prompt in Cursor and let it merge for you.
  3. Enable the perfect MCP in Cursor Settings → MCP. This panel becomes Linked to Cursor.

Token stays local. Anyone with your mcp.json can drive this bridge — same class of risk as a local API key.

Modeled on Claude for Chrome. Default is Manual.
