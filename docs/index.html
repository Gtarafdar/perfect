Perfect

Cursor’s hands in Chrome — a free, unofficial MCP bridge so agents work in your real browser session, in a visible tab group you can still use.

Download zip ★ Star on GitHub Donate

Not affiliated with Cursor, Anysphere, Google, or Anthropic. Privacy · README

The bind

Cursor is brilliant in the repo. The browser was the missing limb.

Out of the box, Cursor doesn’t give you trustworthy hands in the Chrome you already live in — cookies, SSO, the messy real web. Stock agent browser paths often lean on broad Mac automation permissions, then hog the machine while the run is live. Hard to ship real R&D when your desk is held hostage.

Perfect is the bridge I needed: local MCP, your real Chrome, a green Perfect tab group you can see, Manual approvals by default, and a Stop that actually stops.

Without Perfect

  • No native Cursor ↔ Chrome MCP path for your logged-in session
  • OS-level automation that fights you for the desktop
  • Guessing whether the agent is safe on checkout or Buy now

With Perfect

  • Local token bridge · Linked in the side panel
  • Agent work stays in a visible Perfect tab group
  • Manual / Auto / Skip with prohibited actions hard-blocked

Try a prompt

Paste once. Watch the chain.

Perfect doesn’t invent a special search API. Agents chain real tools — navigate, wait, snapshot, press — on sites you approve.

How to connect

          
About two minutes to Linked.

          
    
            
  1. 
              Install the zip
              
    
                Download from
                GitHub Releases,
                unzip, Chrome → chrome://extensions → Developer mode → Load unpacked →
                select the folder with manifest.json.
              
    
            
    2. 
            
  2. 
              Copy the setup prompt
              
    Open Perfect → Copy setup prompt for Cursor. It merges only the perfect MCP entry (npx -y perfect-mcp, GitHub fallback if needed).
    
            
    3. 
            
  3. 
              Enable in Cursor
              
    Settings → Tools & MCP → enable perfect (toggle off/on if it was already on). Node.js 20+ required.
    
            
    4. 
            
  4. 
              Confirm Linked
              
    Side panel shows Linked to Cursor. Agent tabs appear in the green Perfect group. Reconnect pings without tearing down a live bridge.

Permission & safety

          
You stay in the loop.

          

            Modeled on Claude-for-Chrome-style gates. Default is Manual. Skip is dangerous — prohibited actions still hard-block.
          

          

            

              
Manual

              
Ask before acting. Safest default for live R&D.

            

            

              
Auto

              
Fewer prompts on trusted sites; protected and new hosts still pause.

            

            

              
Skip

              
Dangerous. Checkout / Buy now / Pay now stay prohibited.

            

          

          

            Stop in the side panel or on-page HUD cancels work and detaches the debugger.
            The debugger permission is only for local Chrome DevTools Protocol automation — not remote control by a Perfect server.
          

        

      


      

        

          
Honest limitations

          
Useful without overclaiming.

          
    
            
  • 
              Heavy SPAs can be flaky to snapshot
              
    YouTube and similar sites may need navigate + wait + screenshot + keyboard (k) instead of a perfect accessibility tree.
    
            
    • 
            
  • 
              No dedicated browser_search API
              
    Search is navigate + fill + click like a person. That’s intentional.
    
            
    • 
            
  • 
              Chrome MV3 + Node locally
              
    You need Node.js 20+ for the MCP server via npx. Extension alone is not enough.
    
            
    • 
            
  • 
              Chrome Web Store pending
              
    Ship via GitHub Releases today. CWS listing is coming soon — store draft lives in the repo.
    
            
    • 
          

        

      


      

        

          
Privacy by default

          
No Perfect cloud in v0.2.

          

            

              
On your machine

              
Bridge token, permission preferences, welcome-seen flag, local audit log.

            

            

              
To your MCP client

              
Snapshots and page text flow only over the local MCP connection you configure. That client’s policy applies next.

            

            

              
Never by Perfect

              
No Perfect analytics SDK. No sale of personal data. Full policy on the privacy page.

Why I built this

            
I needed hands in Chrome without surrendering the Mac.

            

              I use Cursor every day. The moment the work left the repo — live forms, WPBakery builders,
              real research tabs, media checks — I hit the same wall: there was no clean, local, permissioned
              bridge into the browser I already trust.
            

            

              The alternatives asked for heavy OS permissions, then made the machine feel occupied while the
              agent ran. That’s fine for a demo. It’s terrible for shipping.
            

            

              So I built Perfect: MCP on localhost, a token you own, a side panel that says Linked, a green tab
              group you can see, Manual by default, Stop when you need it. Free, open source, unofficial —
              because the gap was real.
            

          

          

            
What I needed

            
Same cookies. Same session. Visible agent tabs. Approvals I control. No Perfect cloud watching.

            
Who it’s for

            

              Anyone doing live R&D with Cursor — marketers, builders, researchers — who wants real execution
              in Chrome without losing the desk.

FAQ

          
Straight answers.

          

            

              Is Perfect affiliated with Cursor?
              
No. Unofficial open source — not affiliated with Cursor, Anysphere, Google, or Anthropic.

            

            

              Does Perfect upload my browsing to a cloud?
              
No Perfect cloud in v0.2. Token and preferences stay local. Tool results go only to your configured MCP client.

            

            

              What do I need besides the extension?
              
Node.js 20+ so Cursor can run npx -y perfect-mcp (GitHub fallback if the npm package isn’t published yet).

            

            

              Is the Chrome Web Store listing live?
              
Not yet — coming soon. Install from GitHub Releases for now. Store draft: docs/store-listing.md in the repo.

            

            

              License?
              
MIT. Free to use, fork, and share.
